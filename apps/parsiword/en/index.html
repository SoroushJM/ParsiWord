View and edit right-to-left Markdown with an editable live preview. A free RTL Markdown editor for Persian, Arabic and mixed RTL/LTR text, with Word and PDF export.

Why ParsiWord?

Right-to-left Markdown should be easy to read and edit. ParsiWord brings Markdown source and an editable live preview together, so you can work with Persian and Arabic alongside English, numbers and equations in the right direction.

Edit the Markdown source or write directly in the preview; both views stay in sync. Then save the same document as Word or PDF with embedded fonts.
