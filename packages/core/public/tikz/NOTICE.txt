ParsiWord offline TikZ runtime — third-party notices
==================================================

This directory contains a pinned distribution of @rod2ik/tikzjax 1.6.0,
not a new implementation of TeX or the TikZ language. The TeX worker runs
locally. ParsiWord adds a restricted asset transport, serial scheduling,
timeouts and sanitized, self-contained SVG font outlines.

TeX packages and formats
-----------------------
The compressed tex_files assets are complete, unmodified TeX source files
with their own copyright and license headers. Their .gz.bin suffix avoids
HTTP Content-Encoding decompression; the underlying gzip bytes are intact.
The preload includes LaTeX, standalone, xcolor and PGF/TikZ. LaTeX and most
support packages use LPPL; PGF code offers GPL-2.0 or LPPL-1.3c; pgfplots
uses GPL-3.0-or-later. Other included packages retain their individual
headers. See licenses/LPPL-1.3c.txt, licenses/PGF-LICENSE.txt and the full
GPL text. Complete source distributions and documentation:

Mathematical fonts / generated outlines
---------------------------------------
BaKoMa-CM and BaKoMa-AMS fonts are copyright 1994, 1995 Basil K. Malyshev.
Their license permits use, embedding and modified redistribution; the full
copyright, author and permission notice is in licenses/BaKoMa-Fonts.txt.
Original fonts: https://ctan.org/tex-archive/fonts/cm/ps-type1/bakoma
TikZJax converts original OTF files to WOFF2. ParsiWord's vendor script
uses fontkit 2.0.4 to derive glyph outlines and advances from those WOFF2
files. Generated glyphs/*.json.gz.bin are modified font representations;
the font outlines themselves are not relicensed as ParsiWord code.
