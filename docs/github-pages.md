# انتشار وب روی GitHub Pages

نسخهٔ وب یک سایت ایستا است و روی خود GitHub Pages اجرا می‌شود؛ سرور برنامه،
کلید API، secret دستی یا دامنهٔ اختصاصی لازم ندارد. این مخزن آمادهٔ انتشار
است. نشانی نسخهٔ وب این پروژه:
[پارسی‌ورد در GitHub Pages](https://soroushjm.github.io/ParsiWord/).

مخزن عمومی: [SoroushJM/ParsiWord](https://github.com/SoroushJM/ParsiWord).
هر push به `main` تست و ساخت نسخهٔ وب را اجرا می‌کند و در صورت موفقیت،
نسخهٔ جدید را منتشر می‌کند.

## راه‌اندازی

1. سورس را در مخزن GitHub خودت روی شاخهٔ `main` قرار بده.
2. در **Settings → Pages → Build and deployment**، مقدار **Source** را روی
   **GitHub Actions** بگذار.
3. سورس را به `main` push کن؛ یا در **Actions → Deploy web app to GitHub Pages**،
   گزینهٔ **Run workflow** را بزن.
4. پس از موفقیت job انتشار، نشانی واقعی سایت در محیط `github-pages` و
   صفحهٔ Pages همان مخزن دیده می‌شود.

workflow در [.github/workflows/pages.yml](../.github/workflows/pages.yml)
ابتدا وابستگی‌ها، تست‌ها و build را اجرا می‌کند، سپس پوشهٔ `dist` را با
Actions رسمی Pages منتشر می‌کند. اگر شاخهٔ اصلی مخزنت نام دیگری دارد،
`branches: [main]` را در همین فایل تغییر بده.

مسیر سایت از `actions/configure-pages` گرفته می‌شود؛ بنابراین هر دو حالت
`https://USER.github.io/REPOSITORY/` و سایت ریشهٔ دامنه پشتیبانی می‌شوند.
JavaScript، CSS، آیکن، فرمول و فونت‌های همراه از مسیر درست همان سایت خوانده
می‌شوند. پیش‌فرض build معمولی `./` است؛ برای هاست پوشه‌ای دیگر می‌توان
`VITE_BASE_PATH=/REPOSITORY/` را هنگام `npm run build` تنظیم کرد.

## اطلاعات جست‌وجو و اشتراک‌گذاری

نسخهٔ فارسی در ریشه و نسخهٔ انگلیسی در [`en/`](https://soroushjm.github.io/ParsiWord/en/)
قرار دارد. هر دو HTML مستقل با عنوان و توضیح متمرکز بر **RTL Markdown editor**،
نشانی canonical، پیوندهای متقابل `hreflang`، تگ‌های Open Graph و Twitter و
دادهٔ ساختاریافتهٔ `WebApplication` دارند. فایل
[`sitemap.xml`](https://soroushjm.github.io/ParsiWord/sitemap.xml) هر دو زبان را
معرفی می‌کند. معرفی اولیه پیش از اجرای JavaScript در HTML موجود است و بعد
با ویرایشگر جایگزین می‌شود؛ بخش «چرا پارسی‌ورد؟» در خود برنامه هم نمایش داده می‌شود.

انتخابگر زبان در بالای صفحه، زبان رابط را بدون بارگذاری مجدد تغییر می‌دهد.
زبان رابط مستقل از جهت سند است؛ انتخاب English متن RTL را LTR نمی‌کند و
پیش‌نویس، نام سند و تنظیمات را عوض نمی‌کند. ترجمه‌ها در `packages/core/src/locales/en.json`
و مدیریت زبان در `packages/core/src/locale.tsx` است. لینک پروفایل مالک و سورس در footer قرار دارد.

برای دامنه یا نام مخزن متفاوت، نشانی‌های `apps/parsiword/index.html`، `apps/parsiword/en/index.html`، `packages/core/src/locale.tsx` و `packages/core/public/sitemap.xml`
و پیوندهای README را هم تغییر بده. `robots.txt` فقط در ریشهٔ یک دامنه معتبر
است؛ قرار دادن آن در زیرپوشهٔ این پروژه سیاست خزیدن کل دامنه را تغییر نمی‌دهد.
نمایه‌سازی و رتبهٔ جست‌وجو به خزیدن موتور جست‌وجو وابسته‌اند و فوری یا تضمینی نیستند.

## قابلیت‌های مرورگر

ویرایش Markdown، ویرایش پیش‌نمایش، باز کردن فایل محلی، ذخیرهٔ پیش‌نویس روی
دستگاه و دانلود Word، PDF و Markdown در مرورگر انجام می‌شوند. خروجی‌ها فایل
واقعی دانلودشدنی‌اند و به backend یا نصب برنامهٔ اندروید وابسته نیستند.
داده‌های مرورگر و پیش‌نویس به همان origin سایت وابسته‌اند؛ تغییر دامنه
پیش‌نویس قبلی را به دامنهٔ جدید منتقل نمی‌کند.

پس از بارگذاری برنامه، فونت‌های همراه، فرمول و نمودار به سرویس خارجی نیاز
ندارند. دریافت فونت جدید اینترنت می‌خواهد؛ فونت دانلودشده برای استفادهٔ
بعدی و جاسازی در Word روی دستگاه نگهداری می‌شود. متن سند برای دریافت فونت
ارسال نمی‌شود. این سایت service worker ندارد؛ بارگذاری مجدد کامل سایت در
حالت آفلاین به cache مرورگر وابسته است.

## فهرست فونت‌های وب

[packages/core/public/font-catalogue.json](../packages/core/public/font-catalogue.json) نشانی TTFهای ایستا
و وزن‌های قابل دریافت را دارد؛ مرورگر فایل را از همان سایت و فونت را
مستقیماً از `fonts.gstatic.com` می‌گیرد. دکمهٔ به‌روزرسانی فهرست در وب آخرین
snapshot منتشرشدهٔ سایت را می‌خواند؛ دانلودکنندهٔ بومی همچنان از metadata
زندهٔ Google استفاده می‌کند.

برای بازتولید snapshot از کاتالوگ همراه پروژه، با Node 24 اجرا کن:

```sh
node scripts/refresh-web-fonts.mjs
```

فایل تولیدشده را همراه سورس commit و منتشر کن؛ build عادی به تولید دوباره
یا اینترنت برای دریافت metadata فونت وابسته نیست. در محیطی که اتصال Node
باید از proxyهای متغیر محیطی عبور کند، همین فرمان را با گزینهٔ
`node --use-env-proxy scripts/refresh-web-fonts.mjs` اجرا کن.
