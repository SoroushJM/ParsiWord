# رنگ‌آمیزی کد

بعد از سه بک‌تیک، زبان را بنویس؛ نمونه:

````markdown
```typescript
const version = 19; // React
```
````

پردازش با بستهٔ `common` از highlight.js 11.12.0، کاملاً آفلاین است.
فقط همان ۳۶ دستور زبان همراه اپ هستند؛ نام‌های مستعار مثل `js`، `ts`،
`html`، `yml` و `cs` هم پذیرفته می‌شوند. حروف بزرگ/کوچک اهمیتی ندارند.
عنوان زبان، رنگ‌ها و سبک‌های متن در پیش‌نمایش و فایل Word یکسان‌اند؛
Word از متن‌های رنگی قابل ویرایش استفاده می‌کند. کد تصویر نمی‌شود.

زبان نامشخص یا بدون پشتیبانی، با حفظ متن به‌صورت ساده صادر می‌شود؛ تشخیص
حدسی فعال نیست. `plaintext` عمداً بدون رنگ‌آمیزی است. برای جلوگیری از
توقف رابط، بلوک بزرگ‌تر از ۵۰ هزار نویسه هم به‌صورت متن کامل و ساده حفظ
می‌شود. فرمول‌های `math`/`tex`/`latex` و نمودار `mermaid` مسیر قبلی خود را دارند.

## ۳۶ زبان و قالب همراه

`bash`، `c`، `cpp`، `csharp`، `css`، `diff`، `go`، `graphql`، `ini`، `java`،
`javascript`، `json`، `kotlin`، `less`، `lua`، `makefile`، `markdown`،
`objectivec`، `perl`، `php`، `php-template`، `plaintext`، `python`،
`python-repl`، `r`، `ruby`، `rust`، `scss`، `shell`، `sql`، `swift`،
`typescript`، `vbnet`، `wasm`، `xml` و `yaml`.

HTML با `html` یا `xml`، و JSX با `javascript` یا `jsx` شناخته می‌شود.
این انتشار بستهٔ کامل ۱۹۳ زبان را اضافه نمی‌کند.

## حفظ متن و آزمون

خروجی highlight.js فقط برای استخراج محدوده‌های رنگ استفاده می‌شود؛ HTML
آن در صفحه اجرا نمی‌شود. گره‌های متنی React و runهای واقعی Word از یک
فهرست توکن ساخته می‌شوند. متن بازسازی‌شده با اصل مقایسه می‌شود تا هیچ
نویسه‌ای هنگام خواندن entityها یا محدوده‌های تودرتو حذف نشود. فاصله‌ها،
تب‌ها، خط‌های خالی و کامنت چندخطی حفظ می‌شوند. جهت پاراگراف کد LTR است و
فونت کد و جایگزین فارسی آن، مثل قبل همراه Word قرار می‌گیرند.

متن نخست، بخش قبلی فرمول و نمودار، همهٔ S01–S14، مورد عمدی E01، جدول
P01–P72 و نمونهٔ هر ۳۶ زبان را دارد. نمودار/فرمول نامعتبر در این مجموعه
نیست؛ تست‌های خطای آن‌ها جداگانه‌اند. تصویرهای مرجعِ ابزار قدیمی به متن
شروع اضافه نشده‌اند و مقدمه نیز ادعای داشتن آن تصویرها نمی‌کند.

۳۵ نمونهٔ زبان از تست‌های رسمی highlight.js در commit
`f7f7d3803bd898e37c017ffb881317f0cde04a70` گرفته شده‌اند؛ نمونهٔ C متعلق به
پروژه است. مجوز BSD-3-Clause و منبع در `packages/core/public/licenses/highlight.js` هستند.
