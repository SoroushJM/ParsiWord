# نسخهٔ ۰.۴.۵

[دانلود APK آزمایشی ARM64 از Gofile](https://gofile.io/d/am3lcwW3)
— نسخهٔ `0.4.5-preview`، مخصوص Android 7+، با نام **ParsiWord Preview**.
حجم فایل ۹٬۱۲۹٬۵۸۷ بایت (حدود ۸٫۷۱ MiB) است.

در موبایل، انتخابگر چسبان «ویرایش متن / پیش‌نمایش» فقط یک پنل را نشان
می‌دهد. تغییر حالت، جای متن و انتخاب قبلی را حفظ می‌کند و صفحه‌کلید را
خودکار باز نمی‌کند. دسکتاپ همچنان دو ستون دارد. اسکرول دو بخش بر اساس
بلوک‌های منبع در هر دو جهت هماهنگ است؛ تغییر عرض صفحه، سطرهای بلند و
تغییر ارتفاع پس از رسم Mermaid هم در این هماهنگی لحاظ می‌شوند.

پیش‌نمایش اکنون ویرایشگر مستقیم متن قالب‌بندی‌شده است. تغییرهای آن در
Markdown همان سند و ذخیرهٔ خودکار منعکس می‌شوند. نوار ابزار شامل متن
عادی و تیترهای ۱ تا ۶، پررنگ/مورب/خط‌خورده، فهرست بولت‌دار و شماره‌دار،
تورفتگی، نقل‌قول، کد، پیوند، جدول، فرمول، پاک‌کردن قالب‌بندی و واگرد/انجام
دوباره است. ابزار جدول افزودن و حذف ردیف و ستون دارد؛ فرمول و منبع نمودار
نیز در پیش‌نمایش قابل ویرایش‌اند. نوار موبایل دو ردیف با اسکرول داخلی است.

خواندن و نوشتن Markdown با remark انجام می‌شود؛ بلوک‌های دست‌نخورده
منبع خود را حفظ می‌کنند. فرمول‌ها، کد و نشانه‌گذاری‌های ناشناخته با ویرایش
بخش دیگری از سند از بین نمی‌روند. شکست خط سلول جدول با `<br>` در Markdown
و شکست خط واقعی در Word نگه داشته می‌شود. محدودیت ۵۰۰ هزار نویسه،
فونت‌های جاسازی‌شده، متن دوجهته و خروجی قابل ویرایش کد و فرمول حفظ شده‌اند.

اندازهٔ نمودارهای Mermaid با متن متناسب شده است. نمودار عریض داخل محفظهٔ
خودش اسکرول می‌شود؛ راهنمای افقی فقط هنگام وجود محتوای عریض دیده می‌شود.
ابزار عکس هم انتخاب حالت با `--view edit|preview` و اطلاعات دیده‌شدن
پنل‌ها، نوارها و فعال‌بودن ویرایش پیش‌نمایش را گزارش می‌کند.

## اعتبارسنجی رابط و تبدیل

۸۶۹ تست واحد، ۲۹ تست Chromium، بررسی همگامی متن شروع و ساخت
TypeScript/Vite پاس شدند. آزمون‌ها ویرایش پیش‌نمایش، رفت‌وبرگشت Markdown،
ذخیرهٔ پیش‌نویس، Word واقعی و فونت‌های داخل آن، جهت متن، اسکرول دوطرفه،
عرض ۳۲۰px و رسم دیرهنگام نمودار را پوشش می‌دهند. عکس‌های واقعی موبایل و
دسکتاپ با [ابزار پروژه](../ui-capture.md) بازبینی شدند و سرریز افقی صفحه
وجود نداشت. این بررسی مرورگر، تأیید نصب و اجرای بومی روی گوشی نیست.

## ساخت APK آزمایشی ARM64

پیش‌نیازهای Android در [README](../../README.md) و
[راهنمای بسته‌بندی](../android-packaging.md) آمده‌اند. فرمان زیر APK آزمایشی
را با پروفایل release، بهینه‌سازی Android، معماری فقط ARM64 و امضای محلی
می‌سازد؛ پرچم‌های debuggable و testOnly برای این مسیر فعال نیستند:

```sh
PARSIWORD_SIGNING_DIR=/path/outside-repository/signing npm run android:test-apk -- /path/output.apk
```

پیکربندی این نسخه `versionCode=4005`، نام نسخهٔ `0.4.5-preview`، حداقل
Android API 24 و هدف API 36 دارد. شناسهٔ برنامه
`app.parsiword.mobile.preview` و نام نصب **ParsiWord Preview** است؛ بنابراین
می‌تواند کنار برنامهٔ عادی نصب شود. دادهٔ دو نصب جداست.

کلید امضای قبلی همراه آرشیو نبود. مسیر ساخت آزمایشی کلید جدیدی خارج از
مخزن ایجاد می‌کند؛ پوشهٔ تعیین‌شده با `PARSIWORD_SIGNING_DIR` را همراه
فایل رمز آن برای آپدیت‌های بعدی Preview حفظ کن. مسیر پیش‌فرض
`~/.local/share/parsiword/signing` است. فرمان عادی `npm run android:apk`
همچنان شناسهٔ `app.parsiword.mobile` را دارد و کلید اصلی توزیع در سورس
نیست. بستهٔ آزمایشی برای انتشار فروشگاهی امضا نمی‌شود.

اسکریپت ساخت، خروجی را هم‌تراز و امضا می‌کند و سپس
`scripts/verify-android-apk.py` را با شناسهٔ Preview اجرا می‌کند. گزارش
کنار APK با پسوند `.verification.json` ذخیره می‌شود؛ امضا، معماری، نسخه،
ZIP، منابع فرانت‌اند و هم‌ترازی ۱۶KB در این بررسی هستند.

## آیکن دستگاه‌ها

طرح اصلی آیکن با پس‌زمینهٔ مات و foreground شفاف تهیه شده و خروجی‌های
Android، iOS، Windows، macOS و Linux با ابزار icon خود Tauri تولید
شده‌اند. به‌روزرسانی این دارایی‌ها به معنی ساخت باینری‌های همهٔ پلتفرم‌ها
نیست؛ برای ۰.۴.۵ باینری دسکتاپ تازه‌ای ساخته نشده است.
[منبع، manifest و بازسازی آیکن‌ها](../../assets/README.md).

مجوزهای Tiptap، ProseMirror و remark-stringify با نسخه و منبع در
`public/licenses/Rich-editor-MIT.txt` همراه برنامه هستند.

## بررسی APK تحویلی

[گزارش ساخت و بررسی فایل](0.4.5-preview-verification.json) امضای معتبر،
معماری فقط ARM64، نبود debug/testOnly، صحت ZIP، منابع فرانت‌اند فعلی و
هم‌ترازی ۱۶KB را ثبت می‌کند. آیکن داخل بسته نیز با منابع نهایی تطبیق داده
شد. هش MD5 و اندازهٔ گزارش‌شده توسط Gofile با فایل محلی یکسان‌اند؛ صفحهٔ
دانلود پاسخ HTTP 200 دارد. نصب و اجرای روی گوشی را کاربر انجام می‌دهد؛
شبیه‌سازی اجرا نشده است.

```text
SHA256: b631741d5982d20521d22da599e490ac434409080c99c2c6e5c5c9d182a327c2
```
