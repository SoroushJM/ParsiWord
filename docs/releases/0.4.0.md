# نسخهٔ ۰.۴.۰

LaTeX در پیش‌نمایش و به صورت فرمول قابل ویرایش در Word اضافه شد. Mermaid به
صورت SVG در پیش‌نمایش و PNG در Word صادر می‌شود. هر دو روی دستگاه و آفلاین
تبدیل می‌شوند؛ نمونهٔ «فرمول و نمودار» داخل برنامه اضافه شده است.

Git محلی ابتدا با نسخهٔ اندروید تقریباً قابل استفاده ثبت شد (`9439794`)، سپس
هدف‌های دسکتاپ و تنظیمات iOS جداگانه کامیت شدند (`b8ab561`). این نسخه مرحلهٔ
بعدی آن‌هاست؛ هیچ مخزن GitHub یا ریموتی ایجاد یا push نشده است.

۷۹۸ تست واحد و هر ۶ تست مرورگر پاس شدند. خروجی نمونه در LibreOffice بررسی
تصویری شد. برنامهٔ release لینوکس واقعاً اجرا شد و با انتخابگرهای بومی، فایل
Markdown را باز کرد و Word شامل دو فرمول و دو نمودار ذخیره کرد. بستهٔ DEB در
محیط Debian 13 ساخته شده است؛ ساخت برای پایهٔ Ubuntu 22.04 در گردش‌کار CI
آماده شده ولی اجرا نشده است.

نصاب ویندوز cross-compile و ساخته شده است؛ اجرای آن روی خود ویندوز هنوز
آزمایش نشده است. بستهٔ iOS هنوز ساخته یا اجرا نشده؛ macOS و Xcode لازم دارد
و گردش‌کار ساخت شبیه‌ساز آماده شده است. نصب و اجرای اندروید ۰.۲.۴ را کاربر
تأیید کرده؛ برای ۰.۴.۰ بررسی امضا، معماری ARM64، نسخه، ZIP و هم‌ترازی ۱۶KB
پاس شده است و تست گوشیِ این نسخه هنوز انجام نشده است. خروجی اندروید x86
ساخته نشده است.

دامنه و محدودیت‌های ریاضی و نمودار در [rich-content.md](../rich-content.md)
و روش ساخت پلتفرم‌ها در [platforms.md](../platforms.md) آمده است.
